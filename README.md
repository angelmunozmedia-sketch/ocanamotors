# OcañaMotors · Landing de propuesta

Landing estática responsive para presentar el plan mensual de contenido audiovisual de Alexa + Miguel a OcañaMotors.

## Incluye

- Portada con lenguaje visual automotriz abstracto y logo oficial.
- Propuesta, plan mensual, proceso, tipos de contenido, estrategia/métricas y cierre CTA.
- 6 reels mensuales a $150.000 cada uno; inversión mensual total visible de $900.000.
- Reunión de planificación, ideación, guiones, grabación, edición, color, voz/audio, subtítulos/gráficos, métricas y modificaciones.
- Navegación responsive, menú móvil, animaciones de entrada y barra de progreso de lectura.

## Publicar en GitHub / Vercel

Sube el contenido de esta carpeta a la raíz del repositorio. No necesita dependencias ni proceso de compilación: Vercel puede servir `index.html` directamente.

## Archivos

- `index.html` — estructura y contenido.
- `styles.css` — identidad visual y responsive.
- `script.js` — navegación móvil, animaciones y progreso.
- `assets/logo-ocanamotors.png` — logo suministrado.
